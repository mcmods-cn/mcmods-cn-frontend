# 前端异步交互与回退约定

列表、详情和私信完成请求时必须核对当前资源/会话与请求身份。用户改变搜索、语言、资源或账户后，旧请求的成功、失败与 finally 都不能修改新界面。可取消请求传递 AbortSignal；无法取消的协议路径使用本组件请求序号。取消不显示业务失败。

私信状态以认证会话隔离。会话选择立即清空上一会话列表和草稿，并重置增量游标；上一会话发送已落库的迟到结果不会插入新会话或清除新草稿。服务器仍负责会话成员授权。通知客户端译文缓存以目标 locale 和通知 ID 为键，语言变化时回退原文；翻译仅由用户显式操作触发。

异步表单提交在 await 前保存 HTMLFormElement。成功后才重置；失败保留输入并显示错误。管理员封禁的 datetime-local 值按用户本地时区转 ISO/RFC3339 后发送，以匹配后端 time.Time。未填写表示无期限；后台负责期限、角色和原因校验。

评论 mutation 使用 functional state updates 合并当前列表，防止并发完成覆盖其它评论；相同评论/反应的 pending 请求互斥。附件批次上传读取当前附件列表，删除不会被旧快照恢复；disabled 编辑器拒绝拖入上传。上传保存与资源访问权限由后端执行。

资源选择器每次显式搜索都有独立 attempt，相同关键词也能重新查询并结束 loading。模组详情保留 404 状态；网络/其它错误显示实际失败与重试按钮，既有业务内容可按原回退链显示。

Markdown 的图标、视频、时间和引用扩展只在展示文本解析；围栏/行内代码还原为用户原始写法，包括大小写与 legacy vedio 拼写。内部标记同样视为不可信文本，畸形 URI 编码不会抛出渲染异常；不支持的扩展保留原文。测试保留真实 Markdown 解析器。

评论审核、挑战、楼层和限流提示、反滥用管理、资源选择器手动输入及版本摘要均由界面语言词条生成。新增反滥用/资源选择器词条提供中英文，其他语言按现有英语回退显示；回退不表示已有人工译文。管理员风险日期与指标数字按当前 locale 格式化，验证通过/失败分别显示，不把两个计数合并。

验证入口：`npx vitest run tests/frontend-ui-b*.test.tsx`。这些是组件级确定性回归，API/OSS/外部 AI 使用 mock；真实持久化、浏览器、权限、供应商连通性和翻译语义质量须另做集成验收。本次不更改 API/schema，无数据库迁移或前后端同时部署要求。
