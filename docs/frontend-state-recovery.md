# 前端状态隔离与失败恢复

适用于现有 App Router 页面，不改变服务端权限、API 写入政策或生产部署流程。

## 账号、资源与编辑草稿

私信、账号首页、收藏操作、举报、播放器档案以及项目/资源编辑器按登录用户 ID、会话标记和资源 ID 隔离组件状态。Cookie 会话的客户端标记可能保持相同，因此不能只用该标记判断当前用户。切换账号会卸载上一账号的私有正文、表单与任务结果；切换界面语言不会重置仍属于同一账号、资源的未提交编辑。

现有资源、社区帖子、标签和配方类型编辑器必须成功载入原始记录后才提供可提交编辑器或开启自动草稿保存。原始记录加载失败显示错误和重试，避免将空表单写回现有记录。人工选择的内容语言与界面语言是不同概念。

皮肤和蓝图多语言编辑器必须同时成功读取原记录及语言版本快照。语言接口失败不能解释为没有译文，也不能提供只含一种语言的替换提交。重试只读取原记录，不写入；Markdown附件上传未完成时禁止提交。皮肤列表、皮肤详情及播放器档案读取失败可原位重试，保留当前过滤和有效档案选择。

皮肤列表在初次身份确认完成前禁用筛选控件并显示现有加载状态，避免确认后的账号隔离重新挂载清空已输入的条件。身份确认后恢复搜索；切换账号继续隔离状态，列表错误重试保留已经提交的筛选。

主内容写入成功、自动草稿完成标记失败时，提示“内容已保存，但草稿完成状态更新失败”；这不是重新创建内容的依据。社区和更新日志在进入保存结果前明确显示该提示。原记录校验或保存失败保留输入。

## 消息、评论与上传

私信发送期间可以继续输入。响应只清空与已提交正文相同的输入，新输入保留；并发提交有即时守卫，收到的相同消息 ID 不重复追加。通知译文以消息 ID 与目标语言关联，避免语言切换后展示其他语言的迟到结果。

评论写入采用当前状态更新，提交期间输入和附件变更不会被旧响应覆盖。同一评论的相同反应或订阅请求在响应前不能重复启动。附件上传按最终返回的文件 ID 合并，上传期间移除旧附件不会被旧快照恢复。蓝图和皮肤内容上传成功但元数据提交失败，重试复用已取得的上传 ID。

MOD 导入创建/上传尚未完成时不能启动第二个导入，避免覆盖持久恢复标记或误取消第一个上传。取消本页轮询仅停止本页请求，不表示供应商或后端任务已取消。收藏整合包导出预检与当前 Minecraft 版本/加载器必须匹配后才能启动导出；更换选项使旧预检失效。预检、创建和读取任务期间，导出对话框将焦点保留在自身，Tab 和 Shift+Tab 不会进入后台；忙碌结束后恢复正常键盘操作。打开时记录原焦点元素，关闭或卸载后显式恢复焦点且不滚动页面；账号切换已移除的旧元素不会重新取得焦点。

资源选择器按待补全资源的实际 ID、种类、注册表、目标语言和当前会话确定批量展示请求。父组件重新渲染时生成等值的新数组不会再次发送同一请求；资源内容、语言或会话改变仍取消旧请求并读取新范围。

## Markdown 与可访问操作

独立 Markdown 编辑器在身份初始化和已有草稿读取完成后才开放输入、格式工具及上传。读取失败保持这些修改操作禁用，并保留原位重试；不能先允许输入，再让迟到的初次读取覆盖用户编辑。嵌入式编辑器继续由所属资源提供受控正文。

内部 Markdown 私有字符标记不会由原文伪造；非法 URI 编码保留为普通文本，避免渲染抛出 URIError。目录使用实际 Markdown 解析器与相同 remark 插件，忽略代码围栏中的示例标题，排除的标题层级仍参与重复锚点编号。此验证不代表所有数学或自定义富标题组合均已交互验收。

复制失败显示错误，不显示“已复制”。配方模板提供原生键盘可操作的输入、输出、催化剂槽添加按钮。普通编辑表单在提交中禁用字段，避免响应覆盖提交后的编辑；高级战利品 JSON 不接受 null、数组或字符串冒充整体对象。

收藏选择与举报使用原生 dialog 管理焦点与 Escape，提交/上传中禁止关闭。移动页头仍提供语言和主题设置。

主题实心强调色使用 `--accent` / `--accent-strong` 作为背景，使用对应的 `--on-accent` 作为文字颜色；浅色主题为白字，深色主题为深色字。主按钮、选中项、徽标及 Markdown 工具栏沿用同一约定，工具栏子控件不通过叠加半透明白色背景降低对比度。此约定不改变危险按钮或其它独立颜色表面。

## 语言、翻译与费用

界面语言按现有 cookie/provider 规则选择；HTML 首屏使用相同 lang，当前支持的八种界面语言均为 LTR。人工语言词条使用既有回退，不把英文回退计为目标语言语义质量验收。

内容翻译状态等待有 90 秒期限；超时后保留内容并提供“刷新状态”，该按钮只读取已有任务状态，不创建新的翻译请求。AI 成本面板兼容旧统计响应，新增最近 30 天的请求预算状态：已结算 usage、仍预留、usage 未知分别展示。预留费用是配置价格下的保守估算，未知 usage 不表示免费，也不表示已核对真实供应商账单。

## 验证边界

`node --test` 的确定性用例验证日期、CSV 文本公式边界、Markdown 标记与目录解析。`browser-tests/oct02-*.browser.mts` 启动真实 production React 页面，但明确替换本项目 API 响应以控制竞态和失败；它们不证明数据库持久化、服务端授权、真实邮件或付费 AI 质量。真实前后端与 PostgreSQL 联通验证必须另行记录。

当前行为修复不需要数据库迁移；前后端仍须按各自 PR 的新增请求预算字段、任务状态与独立后端修复说明完成兼容部署。不得将这些前端说明视作生产数据库健康证明。

## 分页、旧链接与提交快照

Mod、整合包、简单项目及公共标签/配方类型列表在服务端返回总数后校正超出末页的 URL 页码，并重新查询有效页；不能只修改屏幕上的页数。筛选、排序和搜索参数保留。页码必须为正的安全整数，并避免生成失去精度的分页偏移。

旧标签 `registry/tagId` 与配方类型 `id` 链接经服务端精确 canonical ID 查询取得 public ID，不从模糊搜索的前一页猜测。零结果、重复目标和接口失败保留可见错误与重试。此链依赖后端新增 `/api/v1/tags?canonicalId=...&registry=...` 和 `/api/v1/recipe-types?canonicalId=...`，先部署兼容的后端，再部署前端；响应结构和已有模糊搜索保持兼容，无前端数据库迁移。

服务器提交、评分及下载文件上传在写入期间冻结对应输入并同步排除重复写入；Markdown 附件上传状态与业务请求状态分别维护，不互相解除提交守卫。取消和关闭不卸载尚未完成的服务器或评分提交。失败保留已提交的输入并允许用户纠正或重试。

MOD 导入先成功读取当前任务与本地恢复记录。恢复读取失败时禁止另建上传，提供只读重试，避免覆盖尚未确认的恢复标记。分节资源继续加载的结果、错误和加载状态绑定当前搜索范围，旧搜索的迟到续页不能写入新结果。

Markdown 代码围栏及缩进代码中的自定义标记和缩写定义保持字面内容；GeoGebra 展开使用原生模态对话框，并在关闭后恢复焦点。相关确定性渲染与键盘测试仍不代表第三方服务可用性或所有外部 iframe 的交互已验收。

申请审核队列按固定 50 项和服务端不透明游标加载后续页，并按申请 ID 去除页边界重叠。分页使用同步请求守卫，同一事件循环中的重复点击也只启动一次请求，不能仅依靠尚未渲染的按钮禁用状态。读取范围重置会取消旧请求；旧请求的完成和错误不能修改新范围，只有当前代次能解除其请求守卫。附件下载签名在明确点击附件时请求，不在列表初始化或分页时逐项获取。
