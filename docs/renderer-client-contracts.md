# 资源渲染器客户端边界

结构、模型和皮肤渲染封装均为客户端组件。WebGL 初始化失败时显示局部错误，保留页面的其他操作；这不表示无 GPU 环境可以显示 3D 内容。资源切换/卸载后不继续加载已销毁的结构渲染器，也不回传迟到的封面。新的结构实例继承第一人称模式设置。

`AssetSource` 仅能提供当前导出 revision 的索引资源。后端资源读取路由为 `/api/v1/export-revisions/{revisionId}/assets/content?path={encodedPath}`；浏览器使用 `modExportAssetURL` 保持 URL 编码与 renderer proxy 参数一致。PNG URL 可由受控资源来源返回。

OBJ 的 MTL 贴图引用只有解析到当前 bundle 索引并取得有效 URL 才交给 Three.js。无法解析的 map 指令移除，材质可以缺贴图但不能越过资源来源边界发起外部请求。该保证只覆盖本项目的 MTL 重写路径，不宣称整个第三方渲染库不存在其他网络行为。

皮肤/披风纹理独立登记；批量加载失败或组件卸载后，已返回以及迟到返回的纹理均释放。结构内部面裁剪、透明方块遮挡与完整真实 GPU 视觉结果仍应使用代表性结构测试；当前组件回归模拟 WebGL 构造失败，不能替代真实 GPU 验收。

调用代码须在卸载时执行 `renderer.dispose()`，并按 source key 的实际内容版本重建实例。模型权限、资产下载授权和上传扫描仍由后端负责，客户端索引过滤不能替代授权。
